# SimpleMFPScan 设计定稿

> 轻量级 Windows 扫描工具，简化 HP MFP Scan 的操作流程。
> 面向不懂技术、不熟悉电脑的人：打开就能用，不改任何设置也能扫对。
>
> **本文档是唯一权威定稿。** 界面与交互的最终依据是同目录的 `ui-mockup.html`
> （浏览器直接打开即可交互），实现时以它为准，不要凭文字重新设计。

## 一、范围与用户

- 平台：Windows 10/11 桌面应用，单窗口单页面
- 用户：作者本人（家里自用），以及不懂技术、不熟悉电脑操作的人
- 支持设备：**只支持 HP MFP 系列**（Laser MFP / LaserJet MFP / LaserJet Pro MFP）。
  不做 Smart Tank、OfficeJet、DeskJet
- 主用机：HP Laser MFP 136nw（网络连接），**没有进纸器，只能掀盖一张一张放**，
  扫描组件支持彩色/灰度/黑白

## 二、技术栈（2026-10-19 修订：扫描引擎改用 eSCL）

| 层 | 选型 | 说明 |
|---|---|---|
| UI | **mygo 原生 UI**（Go） | 单窗口即时模式 UI，纯 Go 运行时 |
| 扫描 | **eSCL**（Mopria/AirPrint 扫描协议） | 自实现 HTTP+XML 客户端（`escl.go`），不依赖第三方 eSCL 库 |
| 设备发现 | **mDNS / DNS-SD** | 浏览 `_uscan._tcp`，在 `miekg/dns` 上自实现两步解析，只采用 IPv4 |
| 进程架构 | **单进程 64 位** | 扫描走网络 HTTP，不需要厂商驱动或子进程 |
| PDF | `gopdf` | JPG 直接编码 |

实现细节见 `docs\技术笔记-eSCL扫描.md`。

## 三、硬性设计决策

以下决策已与用户逐条确认，**不要重新讨论或擅自更改**：

1. **纯白主题**：只有一套浅色主题，不跟随系统深色模式
2. **零配置持久化**：不写注册表、不建配置目录。扫描原图只放系统临时目录
   （`%TEMP%`），退出即清理；界面列表只加载低清缩略图，双击才读原图。
   设备缓存 `%TEMP%\SimpleMFPScan\devices.json` 只用于下次启动秒开，
   由系统临时目录清理，不作为配置，也不影响最终正确性
3. **状态灯两态**：绿 = 在线，红 = 离线（红色呼吸闪烁）。仅内部颜色映射，
   界面上不出现中间状态文字
4. **术语全用人话**（见第七节对照表），不出现 dpi、ADF、平板等技术词
5. **没有得选才固定**：某参数设备只支持一种时置灰并在标签后注"固定"；
   有多种则正常可选。不做"按机型写死默认值"的预设机制
6. **单页面布局**：左页面区 / 右操作区 / 打印机选择常驻左下状态栏
7. **不给用户看实现细节**：临时目录、内存占用、驱动等信息一律不展示

## 四、设备能力：设备上报，缺省全开（项目核心设计）

能力探测读 eSCL 的 `ScannerCapabilities`（设备必须如实上报）：

| eSCL 能力 | 用途 |
|---|---|
| `ADF` / `AdfSimplexInputCaps` 节点 | 有无进纸口（玻璃板恒可用）|
| `SettingProfiles/ColorModes` | 支持彩色 / 灰度 / 黑白中的哪些 |
| `SupportedResolutions` | 分辨率列表（设备支持多少档就列多少档）|
| `SupportedIntents` | 扫描用途（文档 / 图文混排 / 照片 / 快速预览…）|
| `MaxWidth` / `MaxHeight` | 支持的纸张尺寸（按物理尺寸能否放下判断）|
| `GET ScannerCapabilities` 是否成功 | 是否在线（状态灯用）|

规则：

```
mDNS 发现设备 → 用户选中 → 读 ScannerCapabilities → 界面按能力渲染
   只有一种可选 → 置灰 + "固定"
   多种可选    → 正常可选
   能力缺失    → 所有选项可点（不拿型号表猜）
```

## 五、操作流程

```
打开软件（自动选中设备）
   → 点「扫描」→ 页面区新增缩略图
   → （重复：放纸 → 点扫描 → 追加）
   → 点「导出」→ 选格式 → 填文件名 → 导出
```

- 标题栏：打印机线性图标 + 软件名"惠普MFP打印机扫描工具"

## 七、界面用语（全人话）

| 技术词 | 界面用词 |
|---|---|
| 平板 / Flatbed | 玻璃板 |
| ADF / 送稿器 / RADF | 进纸口 |
| 分辨率 / dpi | 清晰度（直接列 dpi，默认 300，带"推荐"） |
| Intent | 用途（文档 / 图文混排 / 照片 / 快速预览…，全中文） |
| 单面 / 双面 | （不出现，直接写"一次一张"或"自动一张张扫"） |
| 灰度 | 灰度（保留） |

参数提示语示例：
- 清晰度："数字越大越清晰，扫描也越慢。"
- 用途："按内容选，拿不准就用「文档」：图文混排选「图文混排」，照片选「照片」，只想快速看效果选「快速预览」。"
- 放纸方式：玻璃板="掀开盖子，把纸平放在玻璃板上，一次一张"；
  进纸口="整叠纸正面朝上放进进纸口，自动一张张扫（最多 N 张）"

## 八、功能明细

### 1. 扫描
| 参数 | 选项 | 默认 |
|---|---|---|
| 纸张大小 | A4 / A5 / Letter | A4 |
| 清晰度 | 设备支持的所有 dpi（如 100 / 200 / 300） | 300，设备没有 300 时取最接近的一档 |
| 用途 | 设备支持的所有 Intent | 文档（Document） |
| 色彩 | 彩色 / 灰度 / 黑白 | 彩色，不可用时自动落到可用项 |
| 放纸方式 | 玻璃板 / 进纸口 | 按设备能力，不可用项置灰 |

- 点一次扫描追加一批；进纸器模式一批多张
- 扫描中显示进度并可取消；缺纸、卡纸给出明确人话提示
- 设备离线时「扫描」禁用，提示"这台设备没连上，换一台或点 ⟳ 重新检测"

### 2. 页面管理
- 缩略图网格（低清缩略图 + 页码），**双击放大看高清原图**（悬停显示"双击放大"）
- 拖拽排序（抓手提示 `⠿`）、单页旋转（旋转 90° 时缩略图缩至 1/√2 防溢出）、单页删除
- 灯箱：大图 + 上一页/下一页 + 旋转 + 关闭，方向键左右切换，Esc 关闭

### 3. 导出
点「导出」弹对话框，两步：
1. 格式：**PDF（合并成一个文件）** 或 **图片（每页一张 JPG）**
2. 文件名：默认 `扫描_YYYYMMDD_HHMM`
- 点「导出」后弹**系统另存为**（预填文件名），用户在此选最终路径。
  起始目录 = 本次运行内记忆的上次目录；首次为 `文档 \ 扫描件`。
  （2026-10-15 修订：原设计在对话框里放"保存位置 + 更改…"，已去掉——
  路径交给系统另存为，少一层自有 UI。）
- 导出中按钮转"正在导出…"；完成后显示"已导出 …" + "打开所在文件夹"，
  按钮转"再导出一次"，左侧变"完成"
- 导出**不清空页面**（2026-10-15 修订，撤销 §10-2 的"导出后清空"）；
  清空改为独立入口，见 §3.1
- 对话框内的确认一律页面内完成，不依赖系统 confirm

### 3.1 清空页面（2026-10-15 新增）
- 入口：扫描键正下方的「清空页面」次要按钮，无页面或扫描中时禁用
- **二次确认**后才清空（页面内弹窗，文案"要清空全部 N 页吗？清空后无法恢复。"）
- 清空后页面区回空态，状态栏提示"已清空页面"

### 4. 退出
- 有未导出页面时弹一次确认（2026-10-14 敲定，§10-3）

## 九、优先级

**MVP（第一版）**
- 设备枚举 + 状态灯 + 完整设备名 + 能力探测（含内置表兜底）
- 扫描：玻璃板 / 进纸口，色彩与清晰度，追加扫描
- 缩略图 + 双击放大 + 删除 + 旋转 + 拖拽排序
- 导出：PDF / JPG，文件名 + 目录记忆（走系统另存为）
- 临时目录清理（退出与下次启动）

**P1（快速跟进）**
- 更多 MFP 机型预设、PDF 压缩选项、扫描进度精细化

**暂不做**
- 非 MFP 系列机型
- 双面扫描（MFP 系列 ADF 基本不支持）
- 持久化、OCR、云同步、批量队列
- 深色模式、系统托盘、开机自启、多语言
