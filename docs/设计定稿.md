# 快速扫描（quick-scan）设计定稿

> Windows 扫描工具：放纸 → 扫描 → 导出 PDF / JPG。
> 面向不懂电脑的人：打开就能用，默认参数就能扫对。

## 范围

- Windows 10/11 64 位，单窗口
- 支持 eSCL / AirPrint 的扫描仪，与电脑在同一局域网
- 单进程：mygo 原生 UI + 自实现 eSCL / mDNS，不需要厂商驱动

## 硬性决策

1. **只有浅色主题**，不跟随系统深色模式
2. **零配置持久化**：不写注册表、不建配置目录；原图只放 `%TEMP%`。
   正常退出即清；异常退出时目录留着，下次启动提示恢复上次扫描
3. **状态灯**：绿 = 在线，红 = 离线；界面上不出现中间状态文字。
   打印机自身的忙/卡纸状态另外显示，不混进这个灯
4. **全用人话**：不出现 dpi、ADF、平板等术语，见下方对照表
5. **能力由设备上报**：只有一种可选时置灰并标「固定」，多种正常可选；
   能力缺失时不限制选项，不按型号写死
6. **单页面布局**：左页面区 / 右扫描设置 / 底部状态栏
7. **不展示实现细节**：临时目录、内存、驱动等信息一律不出现
8. **系统标题栏**：不隐藏、不自绘；标题为「快速扫描」，
   品牌、拖动和窗口按钮都交给 Windows

## 操作流程

```
打开软件 → 自动选中设备 → 点「扫描」追加页面
        → 点开看大图 / 旋转 / 删除 / 拖动排序
        → 点「导出」选 PDF 或 JPG
```

## 扫描参数

| 参数 | 选项 | 默认 |
|---|---|---|
| 纸张大小 | A4 / A5 / Letter | A4 |
| 清晰度 | 设备支持的 dpi | 300，没有则取最近一档 |
| 扫描内容 | 设备支持的 Intent | 文档 |
| 色彩 | 彩色 / 灰度 / 黑白 | 彩色，不可用时落到可用项 |
| 放纸方式 | 玻璃板 / 进纸口 | 按设备能力 |

- 点一次扫描追加一批；进纸口模式一批多张
- 扫描中显示进度；缺纸、卡纸、离线给明确中文提示
- 设备离线时「扫描」禁用

## 打印机状态

状态灯只说明连不连得上；打印机本身忙不忙、卡没卡纸由设备上报，单独显示。

- 状态栏设备下拉框右侧显示打印机状态：空闲 / 正在忙 / 进纸口卡纸 / 需要检查
- 忙、卡纸、设备停住时「扫描」置灰，按钮下方用一句话说清原因
- 只管和扫描直接相关的状态：进纸口缺纸不算，免得用户疑惑「没纸？」，也免得挡住玻璃板扫描
- 进纸口的状态只在「放纸方式」选了进纸口时才拦；玻璃板照常能扫
- 设备不报状态时不显示、也不拦——不能因为读不到就把按钮锁死

## 页面管理

- 缩略图网格，显示页码；点一下看大图
- 拖拽排序、单页旋转（90° 时缩略图缩至 1/√2 防溢出）、单页删除
- 灯箱：大图 + 上一页 / 下一页 + 旋转 + 删除 + 关闭
- 方向键翻页，Esc 关闭

## 导出

1. 选格式：PDF（合并成一个文件）或图片（每页一张 JPG）
2. 选文件名：默认 `扫描_YYYYMMDD_HHMM`，可用 OCR 识别出的标题
3. 走系统另存为；导出中显示进度，完成后可打开所在文件夹

- 导出不清空页面
- 清空是扫描键下方的独立按钮，需要二次确认

## 退出

有未导出页面时，先在界面内确认一次。正常退出会清空临时页面；
程序崩溃时来不及清空，下次启动会提示恢复或丢弃。

## 界面用语

| 技术词 | 界面用词 |
|---|---|
| 平板 / Flatbed | 玻璃板 |
| ADF / 送稿器 | 进纸口 |
| 分辨率 / dpi | 清晰度（直接列 dpi，默认 300，带「推荐」） |
| Intent | 扫描内容（文档 / 图文混排 / 照片 / 快速预览…） |
| 灰度 | 灰度 |

## 验证

- `just test`：eSCL 能力解析、导出等纯逻辑，用假设备，不需要真机
- 真机：`just run` 启动，确认能发现设备、扫描并导出
